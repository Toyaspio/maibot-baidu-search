用户随后明确确认在指定测试会话实际收到了机器人的回答。结合此前服务器端的真实规划器、搜索返回、结果续接和消息发出记录，真人收发验收已完成。

## 本次完善

- 依据实际 Host 可见性契约，开启时显式设置 Tool 为 visible；关闭并重载后 disabled/hidden，处理器仍即时检查开关。
- purpose 使用正式对象级参数 Schema 限定枚举，防止模型凭猜测填值。只发送最小公开搜索词，忽略宿主的聊天/身份/记忆等上下文参数。
- 新增测试覆盖配置更新 payload 的 plugin_id 以及“Host 先保存配置、再通知 Runner”的真实顺序，保留关闭及重载的严格断言。

Windows 本机缺少完整 Host 的 jsonschema 测试依赖，安装尝试遇到 TLS 连接失败；没有修改或绕过断言。最终将测试源码和纯 Python pytest 依赖置于实际容器 /tmp，使用现有运行依赖完成全部 117 项测试，没有向生产虚拟环境安装测试依赖。

## 实装与保护

仅新增本插件，启用总开关及自主搜索，日总限额 20、Tool 日限额 5，保留默认无重试机制。Key 在用户授权下只写入专用服务器私有配置，权限 0600；不会出现在源码、参数、环境变量、报告、Git 或发布包。

部署前完整保存原有相关插件、配置、插件数据、核心补丁和启动信息；归档全量读取、实际解包、属主权限、JSON/TOML、回滚脚本语法及可行性检查通过。仅重启 MaiBot 核心，没有操作 QQ/NapCat/Xvfb 或修改系统网络、云计费。回滚只移出本次新增插件，保留现有用户数据及搜索额度；未在生产真实执行回滚演练。私有备份路径和回滚命令仅记在本机维护日志，不进入公开包。

收尾确认：原插件源码、策略及全局配置保留，395 条旧好感度键和全部旧印象记录保留，NapCat 启动时间与状态未变。实际互动后，原插件按既有逻辑将两项好感度分数同步到 managed_users；其成员、锁定、备注和其他策略未变，管理表与运行分数一致。本次未回滚这些正常互动更新，不能把这份动态配置描述为部署后字节完全不变。
